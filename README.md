# ice-core — расчётное ядро и расчёты проекта «Интерактивная 3D-модель ДВС»

Репозиторий содержит физическую модель поршневого двигателя внутреннего сгорания, все расчёты отчёта
и сам отчёт. Ядро подключено к 3D-симуляции
[ice-engine-simulation](https://github.com/dvs-physics-project/ice-engine-simulation): каждое число,
которое она показывает, считается здесь.

Проверка модели — двигатель ВАЗ-21126 (паспорт: 72 кВт при 5600 об/мин, 145 Н·м при 4000 об/мин).
Модель без подгонки даёт 61,2 кВт и 121,2 Н·м, то есть на 15–16 % ниже паспорта.

## Структура

```
src/                  расчётное ядро (CommonJS, без зависимостей, СИ)
  geometry.js         блок 1: объёмы, площади, компоновки, фазы цилиндров
  kinematics.js       блок 2: путь, скорость, ускорение поршня (точные и приближённые формулы)
  thermo/             блок 3: свойства газа, заряд, цикл Отто, расчётный цикл, закон Вибе, пошаговый расчёт
  heat/               блок 4: теплоотдача по Вошни, температуры стенок, тепловой баланс
  dynamics.js         блок 5: силы в КШМ, крутящий момент, неравномерность, уравновешенность
  performance.js      индикаторные и эффективные показатели, удельный расход
  engines.js          блок 6: двигатели симуляции I4, B4, V8, параметры дизеля
  intake.js           газообмен по оборотам, наддув
  diesel.js           смешанный цикл дизеля и проверка по расходу топлива
  characteristics.js  скоростные характеристики, формула Лейдермана
  valvetrain.js       блок 7: клапаны, фазы, скорость газа в клапане, приводы
dist/ice-core.js      ядро одним файлом для браузера (копируется в симуляцию как js/ice-core.js)
test/                 38 тестов с контрольными числами отчёта (общие помощники — test/helpers.js)
calc/                 расчёты по разделам отчёта → results/*.json
  first-version-thermo.js  упрощённая термодинамика первой версии симуляции (для таблицы «было → стало»)
results/              результаты расчётов (JSON) и таблица цикла по градусам (CSV)
figures/              построение рисунков отчёта (matplotlib) → figures/png/
report/               сборка отчёта в Word, снимки экрана симуляции, готовый отчёт
tools/bundle.js       сборка dist/ice-core.js из src/
```

## Запуск

Нужны Node 18+ и Python 3 с matplotlib; для сборки отчёта — пакет `docx`, LibreOffice и poppler-utils.
Репозиторий симуляции должен лежать рядом (`../ice-engine-simulation`) или задаётся переменной `SIM_DIR`:
из него берутся размеры, профили кулачков, ремни и шестерни 3D-моделей.

```bash
npm install            # docx — только для сборки отчёта
npm test               # 38 тестов ядра
npm run build          # dist/ice-core.js
npm run calc           # results/*.json
npm run figures        # figures/png/*.png
npm run report         # report/Отчёт_проект_ДВС.docx
npm run all            # всё по порядку
```

## Пример

```js
const Core = require('./src');
const vaz = Core.VAZ21126;
const cycle = Core.simulateCycle(vaz, {}, { rpm: 3000 });
const perf = Core.performance(vaz, cycle.Li, 3000);
const torque = Core.torqueCurve(vaz, Core.layouts.inline4(), cycle.state, {}, 3000);
```

Результат: `cycle.pmax` ≈ 52,7 бар, `cycle.Li` ≈ 389,6 Дж; `perf.Ne` ≈ 34,2 кВт, `perf.Me` ≈ 108,8 Н·м;
средний момент `torque.mean` ≈ 120,2 Н·м.

Все величины в СИ (м, кг, с, Па, К, Дж, Н, Н·м, Вт). Углы кривошипа `alpha` — в радианах, углы с суффиксом
`Deg` (угол цикла 0–720°, угол вала) — в градусах. В начале каждого модуля — список его функций с номерами
формул по документу
«ДВС: теоретико-расчётная база и спецификация ice-core».

## Основные допущения

- Нульмерная модель: давление и температура одинаковы во всём цилиндре; волн давления во впуске нет.
- Сжатие и расширение считаются от НМТ до НМТ (180–540° цикла); угол начала сгорания постоянный.
- Скорость заряда в клапане w = 6,6·c_m (подобрана по номинальному режиму ВАЗ-21126, в методике 50–130 м/с).
- Механические потери: p_м = 0,034 + 0,0113·c_m МПа (бензин), 0,089 + 0,0118·c_m МПа (дизель).
- Массы деталей двигателей симуляции, масса клапана 45 г и момент инерции маховика 0,13 кг·м² приняты без прямых данных.
